# Delta Electric Power

Independent static website for DELTA ELECTRIC POWER. This repository is separate from the MCC website.

## Local preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

The repository is structured for GitHub Pages deployment. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. The generated Pages URL will be shown by GitHub.
